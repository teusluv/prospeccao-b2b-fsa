# ProspectRadar API

Backend Java (Spring Boot) do ProspectRadar. Este Space é publicado pelo script `publicar-huggingface.sh`
do repositório principal: não edite os arquivos aqui, eles são substituídos a cada publicação.

- Saúde: `/actuator/health`
- Documentação: `/swagger-ui.html`

As configurações (banco, JWT, CORS) ficam em **Settings → Variables and secrets** deste Space.
